# Pandora Core

`pandora-core` builds an unsigned Android arm64 payload APK. It contains the
Java component factory, JNI bridge, and C++23 redirector.

## Layout

| Path | Purpose |
| --- | --- |
| `src/main/java/com/pandora/core/` | Component factory and original-factory delegation |
| `src/main/cpp/Core/` | Redirect state, process memory, syscall routing, integrity handlers |
| `src/main/cpp/Jni/` | JNI entry points |
| `src/main/cpp/include/pandora/Redirect.hpp` | Public C++ API |

The CMake build creates a static `PandoraCore` target and links it into
`libpandora-core.so`. The Java entry point is
`com.pandora.core.AppFactory`. The `pandora` builder module embeds the
unsigned payload APK generated by this module.

## Build

```sh
./gradlew :pandora-core:assembleRelease
```

The output is
`pandora-core/build/outputs/apk/release/pandora-core-release-unsigned.apk`.
The module targets arm64-v8a and supports Android API 29 or newer.

## C++ API

```cpp
#include <pandora/Redirect.hpp>

Pandora::Install(OwnApkPath, RedirectApkPath);
bool Active = Pandora::IsActive();
int Tracer = Pandora::TracerPid();
```

The C aliases `pandora_install`, `pandora_active`, and
`pandora_tracer_pid` remain available. `Pandora::Install` starts the tracer
asynchronously, so callers can poll `Pandora::IsActive` for activation.
